How to Edit

怎么录入我自己的档案

全部档案都集中在一个文件里，改完保存、刷新页面就能看到，不需要任何开发环境。

第一步：打开数据文件

用记事本、VS Code 或任意编辑器打开项目里的 assets/js/people-data.js。文件顶部有完整的字段说明， 中间是 const PEOPLE = [ ... ];，每一对花括号 { } 就是一份档案。

第二步：照着模板改

复制文件末尾的「空白模板」，粘贴进数组里填写即可：

{
  id: 'p17',
  name: '张某某',
  cat: '制衣厂主',           // 只能用：制衣厂主 / 配套从业者 / 制衣工人 / 观察者
  hometown: '湖北天门',
  age: '42',
  since: 2010,              // 来康鹭的年份，数字
  years: 16,                // 在康鹭多少年，数字
  tags: ['日结工', '夫妻档', '搬迁中'],
  color: '',                // 留空则按身份自动配色
  quote: '他原话说的一句话。',
  story: '档案正文，可以写很长，需要换行用 <br>。',
  meta: { '厂房面积': '200 ㎡', '工人': '8 人', '关键年份': '2019' },
  source: '2026年3月 笔者于康鹭新招工广场访谈',
  photo: ''                 // 有照片就填 'assets/img/p17.jpg'
},

易错点：请一律使用英文单引号 '； 正文里不要出现未转义的单引号；最后一条档案末尾不要多写逗号。

第三步：可选的照片、分类与其他调整
  • 加照片：把图片放进 assets/img/，然后在档案里填 photo: 'assets/img/p01.jpg'；不填则自动用姓氏首字生成圆形头像。
  • 换配色：在档案里填 color: '#b3452f'；不填则用身份默认色。
  • 加新身份分类：修改 assets/js/people.js 顶部的 CATS 与 CAT_COLOR 两处，然后档案里就可以用这个新分类。
  • 关掉示例提示：把 assets/js/people.js 顶部的 SHOW_SAMPLE_NOTICE 改成 false。
  • 改时间轴、地图节点、词条：编辑 assets/js/data.js，结构与人物档案类似。

批量录入：用 Excel 整理后一键导入

如果档案较多，可以先下载 CSV 模板，在 Excel / WPS 里批量填好，再在这里导入： 页面会立即按新内容预览，确认后可一键导出 people-data.js， 覆盖原文件即可永久生效。整个过程都在本机浏览器里完成，不上传任何数据。

关于本站

康鹭记忆是一项数字人文教学研究项目，以广州海珠康乐村、鹭江村的制衣产业为对象，尝试用结构化数据、空间标注与人物档案的方式，保存一场正在发生的城市变迁。
