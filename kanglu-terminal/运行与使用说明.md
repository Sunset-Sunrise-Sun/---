> 这份说明写给两种人：
> **① 只是要看/分享这个网页的人** —— 看第一章、第二章就够了。
> **② 要维护、改内容、部署上线的人** —— 看第五章、第六章。
>
> 遇到具体问题（打不开、AI 不回答、样式旧了）直接翻第七章「常见问题」。

## 一、这是什么

「康鹭记忆」是一个数字人文网站的成品，对象是**广州海珠区的康乐村与鹭江村**（合称「康鹭片区」）
—— 全国闻名的制衣村，也是广州中心城区投资额最大的旧改项目。

网站把课题组 2026 年 8 月的田野走访、公开报道与政府公开文件，整理成四种可检索的视图：
**空间**（三维街区）、**产业**（工序与背景）、**人**（四份人物档案）、**时间**（变迁编年）。

- 技术上是**纯静态站点**：只有 HTML / CSS / JS 和图片，不需要数据库、不需要后台
- 除了「AI 小白鹭」需要联网调用大模型，**其余部分完全离线可用**
- 全站**不引用任何 CDN、外部字体、外部图片**，所以断网也能完整打开

## 二、三种打开方式

### 方式一：直接在线上看（推荐，AI 也能用）

浏览器打开：

```
https://sunset-sunrise-sun.github.io/---/kanglu-terminal/
```

- 电脑、手机、平板都能开，不需要装任何东西
- **AI 小白鹭在这里可以正常接大模型**（因为站点是 https 域名，走服务器端代理）
- 旧版站点仍保留在 `…/---/kanglu-dh/`，随时可以对照或回退

### 方式二：本机双击打开（看内容、做演示）

1. 解压 `康鹭记忆-终版-交付.zip`
2. **双击** `康鹭记忆-终版/index.html`

就这样，不需要装服务器、不需要联网。

- 建议用 Chrome / Edge / Firefox 的较新版本
- 手机上看也可以，把整个文件夹传到手机再打开
- 这种打开方式下，AI 小白鹭会进入「**站内检索模式**」——从网站自己的数据里找答案并如实标注，
  **不会**调用大模型（原因见第四章）

### 方式三：把文件夹整个发给别人

把 `康鹭记忆-终版` 文件夹（或那个 zip）发给对方，对方解压后双击 `index.html` 即可。

- ✅ 网站全部功能正常：首页、三维街区、四份档案、产业背景、变迁记录、关于研究
- ⚠️ AI 小白鹭只会走站内检索模式（同上）

> **想让对方也用上大模型 AI？** 只能给对方**网址**（方式一）。
> 因为 API 密钥必须留在服务器上，不能放进网页里——这是安全设计，不是 bug。

## 三、七个页面各看什么

顶部导航提供 6 个入口，加上一个人物详情页，共 7 个页面：

| 页面 | 内容 | 建议先看 |
|---|---|---|
| **走进康鹭**（首页 `index.html`） | 全站概览：简介、三维街区入口、一组数字、制衣的人、产业与变迁、发展历程 | 三个「大幅图入口」都可以直接点进去 |

| **变迁记录**（`chronicle.html`） | 视觉化时间轴：轴线 + 年份 + 节点卡片 + 田野引语 + 配图 | 注意每条都区分「已发生 / 规划·预期」 |

  镜头会推过去并弹出地点卡片
- **AI 小白鹭**（右下角）：点一下打开对话框，可以问站内任何内容；有 5 个预设问题可以一键提问

## 四、关于 AI 小白鹭（重要）

### 它有两条路径

| 状态 | 表现 | 触发条件 |
|---|---|---|
| **已接入模型** | 像有人讲给你听，回答里带上站内资料 | 线上有可用的代理地址 |
| **站内检索模式** | 从本站已整理的数据里摘出相关段落，**并在回答末尾如实标注**「站内检索模式，未接入大模型」 | 没有任何可用接口时自动降级 |

界面上会显示当前处于哪一种。**降级不是故障**：网站刻意保证「即使接口挂了、断网了，
用户仍然能拿到有出处的答案」，而不是留一个转圈的空窗。

### 为什么"发文件夹给别人"时只能走检索模式

大模型 API 需要一个密钥。密钥一旦写进网页就是公开泄露（任何人都能在浏览器里翻出来），
所以本站的规矩是：

- **密钥只留在服务器**（Cloudflare Worker 的环境变量里）
- 网页里只放一个**代理地址**，前端跟代理说话，代理再拿密钥去问大模型
- 而"双击本地文件打开"时，页面既没有代理、也不该带密钥 → 于是降级为站内检索

结论：**想让 AI 接上大模型，就必须有一个公网网址**（方式一）。

## 五、维护：怎么改内容

改内容**不需要碰页面结构**，绝大多数内容集中在两个数据文件里：

| 想改什么 | 改哪个文件 |
|---|---|
| 数字、时间、工序、词条、参考文献、空间节点 | `assets/js/data.js` |
| 四份人物档案 | `assets/js/people-data.js` |
| 首页六宫格数字与占比条 | `data.js` 的 `STATS` / `index.html` 里的 `BARS` |
| 三维街区的场景与地标 | `assets/js/scene3d.js`（**改完必须重新打包**，见下） |
| 点地标弹出的地点卡片文案 | `assets/js/map3d.js` 里的 `INFO` |
| AI 的标题、预设问题、人格设定 | `assets/js/ai-config.js` |

**改完 `scene3d.js` / `map3d.js` 必须重新打包**（浏览器在 `file://` 下禁止加载 ES 模块，
所以源码是 ESM，交付用的是 esbuild 打好的传统 script）：

```
cd 人文数字-网站
node _build-final.js      # 产物：康鹭记忆-终版/assets/js/scene-bundle.js
```

改 CSS 或 HTML、改 `data.js` 这类传统脚本**不需要**打包，刷新页面即可。

## 六、维护：怎么更新线上站点

站点通过 **GitHub Pages** 发布，仓库是 `Sunset-Sunrise-Sun/---`，
新版放在 `kanglu-terminal/` 子目录（旧版 `kanglu-dh/` 保留）。

### 更新流程（在本机 `人文数字-网站` 目录下）

```powershell
# 1) 把终版目录的内容同步到部署目录（排除含密钥的本地配置）
#    手动做就是：把 康鹭记忆-终版\* 复制到 kanglu-terminal\ 覆盖

# 2) 推送（本机访问 GitHub 需要走代理）
git add kanglu-terminal
git commit -m "说明这次改了什么"
git -c http.proxy=http://127.0.0.1:7890 -c https.proxy=http://127.0.0.1:7890 push origin main
```

推送后等 1—2 分钟，GitHub Pages 会自动重新发布。

### 重新打包交付 zip

```powershell
cd 人文数字-网站
node _pack-final.js
```

它做四件事：全站自检（7 页 / 资源 / 断链图片）、**密钥泄漏扫描**（发现 `sk-` 串即中止）、
生成 `康鹭记忆-终版-交付.zip`、清理临时目录。

### 换 AI 的密钥（正常一年也做不了一次）

密钥有两处，**互相独立**：

1. **线上**（给所有访客用）：存在 Cloudflare Worker 里，不在任何文件里
   ```powershell
   cd worker
   wrangler secret put DEEPSEEK_KEY     # 粘贴新密钥
   ```
2. **本机演示**（只有你自己用）：写在 `_ai-config.local.js`（在项目根目录、与终版文件夹**平级**，
   已被 `.gitignore` 忽略、**不会随交付包发出**）

> ⚠️ 不要把密钥写进 `ai-config.js`——那个文件会随站点公开发布。

## 七、常见问题

**Q：打开后样式是旧的（图片偏窄、工序是三行）？**
按 **Ctrl + F5** 强制刷新。本地打开时浏览器缓存有时会留旧版本。

**Q：三维街区一片空白 / 提示初始化失败？**
① 换个较新的 Chrome 或 Edge；② 确认显卡驱动正常（三维用的是 WebGL）；
③ 页面本身有错误兜底，会把真实错误显示在页面上。

**Q：AI 小白鹭说"站内检索模式"？**
分两种情况：
- **本地双击打开**：这是正常的、预期的（见第四章），想用大模型请看线上网址
- **线上网址**：说明代理没通。按顺序查：① 那把密钥是否有效（可直连 DeepSeek 测一下）
  ② Worker 里的密钥是否完整（长度 35、无空格、无不可见字符）
  ③ Worker 的 `ALLOW_ORIGINS` 是否包含站点来源 ④ 页面里的代理地址是否填对

**Q：图片显示不出来？**
如果是从 zip 解压的，注意**要解压后再打开**，不要直接在压缩包里双击。
另外确认 `assets` 文件夹与 `index.html` 在同一层。

**Q：手机上看排版乱？**
本站已做手机适配（图片单列、工序链变竖排向下箭头）。如果很窄，属正常重排，不是错版。

**Q：能改内容后重新分享吗？**
可以。改完双击验证 → `node _pack-final.js` 重新打包 → 把新 zip 发给对方。
如果改了 `scene3d.js`，记得先 `node _build-final.js` 打包。

## 八、几条使用与引用上的注意事项

这些是本站内容层面的硬规矩，引用或转载时请一并遵守：

- **三维街区是示意性重建，不是测绘成果** —— 地标位置按公开地图与现场照片推断，
  不代表真实坐标，不可用于地籍、规划等实务用途
- **人物配图一律是"环境影像，非本人肖像"** —— 我们没有取得可公开的肖像授权，
  不把画面里的路人指认为任何一位受访者
- **数字必须带范围与来源** —— 站内数字来自不同年份与统计范围，**不能相加或互相推算**；
  来源不明的会标「口径待核」，详见「关于研究 · 统计口径」
- **变迁记录区分「已发生 / 规划·预期」** —— 规划中的内容不等于既成事实
- **缺影像的环节如实写"暂无现场影像"**，不用无关图片或生成图充数
- **不含具象人形** —— 三维场景里没有人物模型
